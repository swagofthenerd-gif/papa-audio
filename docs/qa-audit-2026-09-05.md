# Papa Audio full-app QA audit — 2026-09-05

How this was produced: a sandboxed second instance of the real app (full clone of the
real profile, muted, isolated userData) was driven for an extended live session over the
DevTools protocol — real dispatched clicks and keys, every result verified both in DOM/state
and visually via screenshots. In parallel, three read-only code audits (main process,
renderer, providers/catalog/CSS) traced every reported item through source. Items marked
CONFIRMED were reproduced live; items marked TRACED were verified in code by a second
reading; anything neither reproduced nor traced was dropped.

Legend: [P1] fix first · [P2] fix soon · [P3] polish / latent

## Confirmed live, user-visible

1. [P1] **Invisible click-blocking overlays when window unfocused** — `body.app-unfocused *`
   pauses ALL animations (styles.css ~5883). Any fade-in surface (fullscreen player, dialogs,
   sleep panel, toasts) opened while the window is unfocused freezes at opacity:0 frame 0 —
   invisible but intercepting every click. Reproduced 100% via unfocused np-modal:
   display:grid, opacity:0, elementFromPoint = modal art. Fix: pause only looping animations,
   or exempt one-shot entry animations / force them to end state.
2. [P1] **Bar heart and fullscreen heart "like" the ALBUM, not the song** (renderer ~22181:
   toggleLike(albumId); np-modal-like delegates to it) while Liked Songs lists TRACK likes
   only → hearts from the bar never appear in Liked Songs. Live: click → likedAlbums 4→5,
   likedTracks 0, Liked Songs "0 songs". Decide semantics, then wire bar/fullscreen hearts
   to track-like (Spotify convention) or show album-likes in Liked Songs.
3. [P1] **Video search history records every keystroke** — papaVideoRecentSearches contains
   "toky","tokyo r","tokyo re","tokyo rev"… Record on commit (Enter / result click), not on
   the search debounce.
4. [P2] **Giant "Made by" avatars on video detail** — .vcast-rail grid-auto-columns:
   minmax(104px,1fr): with few crew members each column stretches to ~700px and
   .vcast-photo{width:100%} fills it (reproduced: 632px circles). Cap the max
   (e.g. minmax(104px,140px)).
5. [P2] **Ghost "Untitled" card in Continue Watching** — watch-store entry keyed "movie:"
   (empty id) renders an empty card; clicking → TMDB 404 error page. Validate id before
   writing history; migration to purge existing empty-id keys.
6. [P2] **Continue Watching shows the same show twice** (TR S1·E25 and S1·E26 as separate
   cards). Collapse to latest episode per show.
7. [P2] **np-modal volume slider desyncs** — shows stale % (live: 80% while volume 0).
   Sync fill/aria from actual volume on modal open and on external volume changes.
8. [P2] **False "watched" from wrong duration** — store entry s1e18: duration 91.095s for a
   24-min episode → position 87.5 auto-marked watched:true. Duration recorded from the wrong
   file (NC/OP extra in pack or pre-load value). Guard: only mark watched when duration is
   plausible (e.g. > 5 min for episodes) or re-verify duration after load settles.
9. [P3] **Lyrics drawer peeks below the player bar when closed** (top line visible;
   translateY(100%+4px) vs bottom offset). Seen in 3 screenshots.
10. [P3] **Album hero prints empty separators when year missing** — "Radiohead • • 10 songs,
    49 min •". Join non-empty segments instead.
11. [P3] **Literal "null" genre chip** for missing-genre albums (plus case-duplicate chips
    like rock/Rock). Map missing to "Unknown"; normalize case for chip identity.
12. [P3] **Library Folders/Grid toggle labels the TARGET state** ("▦ Grid" while in folder
    view) — reads as current state; sort chips stay active in folder view, compounding it.
13. [P3] **Continue Watching header has stray count "9"** floating under the title.
14. [P3] **Following circles blank when artist art missing** (no initial fallback on Home;
    artist-card fallback works elsewhere).
15. [P3] **Downloads badge (97) vs page "136 waiting"** — clarify metrics or unify.
16. [P3] **Diary tab shows 0 films/0 viewings** despite watched store entries — if diary is
    manual-log-only, say so in the empty state; if not, auto-log watched:true.
17. [P3] **video-store.json is double-encoded JSON** (JSON string inside JSON). Works, but
    complicates recovery tooling and doubles escaping.

## Traced in code (static audits) — fix-priority order

Main process / streaming:
- [P1] side-store flushSync races the in-flight async write on the same tmp path →
  shutdown data-corruption window (side-store.js ~133).
- [P1] torrent-stream stop/_onTimeout call destroy({destroyStore:true}) on a REUSED shared
  torrent → deletes another consumer's downloaded data (torrent-stream.js ~1003/~1096).
- [P2] video-play stale load() can hijack a newer engine on rapid double-play (main.js ~8097).
- [P2] stale ffprobe reports old file's audio layout after source switch (no current() check,
  main.js ~7947).
- [P2] thumbs-* dirs under streamRoot never matched by purgeOrphanStreams → accumulate
  across crashes.
- [P2] torrent client-level 'error' only logged; streams wedge silently.
- [P3] video-switch-stream no window/wid re-check after engineDown; reused-torrent
  once('ready') closure leak; >1MB mpv IPC line dropped; _activeTorrents ghost entries;
  video-play error-surface inconsistency.

Renderer:
- [P1] arrow keys scrub music while browsing video grid (music keydown lacks video-page
  guard; preventDefault doesn't stop it) — everyday repro.
- [P1] interlude-skip recursion: repeat-all + mostly <60s tracks → playNext infinite
  recursion (no guard like _skipShortGuard).
- [P2] _autoSwitchSource: no ticket guard, incomplete _watch reset, concurrent switches
  possible; _switchPackEpisode drops pick → stall can re-pick the dead source; auto-advanced
  episode fires stale "Resume from…" prompt. (One shared fix: always rebuild _watch through
  _videoPlayResult.)
- [P2] fullscreen hotkey re-entry stacks focus-trap listeners (no modalOpen guard).
- [P2] clear-queue undo doesn't re-arm gapless prefetch → album stops at next boundary.
- [P3] 3 of 4 shuffle toggles never clear _pendingShuffle; Up-Next chip/modal queue prepend
  file:// to http art (broken art for streamed tracks); toggleAgent shortcut rebind dead
  (hardcoded Ctrl+/); reorderQueue doesn't refresh modal queue; dead #video-episode-select ref.

Providers / catalog:
- [P1] tmdb/omdb/anilist fetches have NO timeout (hang forever; only jikan guarded); anilist
  browse/search/byId let GraphQL errors reject instead of degrading quietly.
- [P2] apibay/knaben/solidtorrents matchesEpisode → accept-all when episode is non-numeric
  (wrong episodes flood the sources list); 'Complete/Batch' keyword accepts packs whose
  stated range EXCLUDES the requested episode (nyaa's range logic is correct — port it).
- [P2] live observation: aggregator seeder counts can be fiction (a "370 seeders"
  SolidTorrents pick delivered 1 real peer). Consider health-weighting aggregator entries
  or verifying peers before auto-pick promotes them.
- [P3] mirror-race lacks its own overall timeout (mitigated by 8s per-backend in prod path).

CSS:
- [P2] later duplicate blocks gut the redesign: .np-modal-lyrics-title/artist (26px white →
  14px var(--text), live-confirmed), .np-stats-pill (var(--text3) on dark), .cinema
  .vshelf-head grid→flex (orphans vrow-note grid-area). Same class as the two already fixed.
- [P2] 8 overlay families tied at z-index 9999 — tooltip/drag-ghost paint over context
  menu/palette; assign a deliberate ladder.
- [P3] dead rules: .np-modal-content chain (idle controls feature partly dead),
  .progress-bar(-fill), .volume-bar/-fill, .selection-count, .ctx-menu class rule, empty
  scrollbar block, 62 stray `;;`.
